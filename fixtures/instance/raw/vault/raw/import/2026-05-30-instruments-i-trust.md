The instruments I trust all share one property: they fail loudly and in a
direction I can predict. A balance that sticks is worse than a balance that
reads high, because the sticking one lets me carry on believing a number that
stopped being measured.

I now hold software to the same standard, which rules out most of it. A tool
that quietly returns fewer results when its input goes missing is a stuck
balance. It will not tell me that the corpus shrank; it will just answer a
smaller question with the same confidence and let me act on the difference.

So the first thing I check in anything new is what it does when something it
depends on is absent. If the answer is "carries on", I stop reading the feature
list. There is nothing further down the page that fixes that.
